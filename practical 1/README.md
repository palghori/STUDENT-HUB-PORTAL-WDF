# StudentHub Pages

This directory contains all the HTML views for the StudentHub portal.

## Files Overview
- `index.html`: The landing page and entry point to the portal.
- `dashboard.html`: The main dashboard view showing upcoming classes, assignments, and attendance.
- `courses.html`: Lists enrolled courses and subjects.
- `assignment.html`: View and manage pending and completed assignments.
- `attendence.html`: Attendance tracking and statistics.
- `result.html`: Academic results and grades.
- `profile.html`: Student profile and personal information.
- `contact.html`: Support and contact form.
- `login.html`: Student authentication login page.
- `register.html`: New student registration page.

## Notes
- All pages share the same `script.css` stylesheet located in the `../CSS/` folder.
- Navigation links are consistent across all these pages.
